### Skill: Update README
#### Objective
Your goal as the Technical Writer is to maintain a pristine, human-readable summary of every milestone achieved in the project.

#### Rules of Engagement
*   **Target Context**: Your focus area is the root `README.md` file.
*   **Save Location**: Always output your final formatted text directly to `README.md`.
*   **Preservation**: Do not overwrite the historical context. Append the latest milestone with a timestamp to the existing document.

#### Instructions
1.  **Analyze Progress**: Review the latest approved `production_artifacts/Technical_Specification.md` and the executed code in the `app_build/` directory.
2.  **Draft the Update**: Write a concise project status update that includes:
    *   **Timestamp**: The current date and milestone version.
    *   **Completed Objectives**: A high-level summary of what was just built or approved.
    *   **Next Steps**: What the upcoming phase entails based on the specification.
3.  **Commit Documentation**: Format the output in standard Markdown suitable for presentation on your GitHub repositories, and save it directly to the root `README.md`.
